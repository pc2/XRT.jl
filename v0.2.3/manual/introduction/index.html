Introduction

The XRT.jl package provides support for simple, user-friendly, yet accurate and fine-grained communication with Xilinx FPGA devices from within Julia. The usage of this package is largely similar to other well-known Julia packages, which are used to communicate with other hardware accelerators. Therefore, the package provides abstraction layers and custom functions, which simplify the appliance. The following documentation is intended to provide users with an insight and a guide to FPGA use with Julia.
